# 주분주분 · japanese-word

> 10分, 十分 — 하루 10분, 일상에 일본어 한 조각.

**주분주분**은 단어를 확인하고, 기억하고 싶은 단어를 저장하고, 다시 복습하는 흐름에 집중한 일본어 학습 웹 서비스입니다. 총 1,000개의 단어를 20개의 Day로 나누어 제공하며, 한 장씩 넘기는 카드 인터페이스로 자신의 속도에 맞춰 학습할 수 있습니다.

회원가입 없이 학습을 시작할 수 있고, 로그인하면 개인 단어장과 Day별 학습 완료 기록을 계정에 저장해 다른 기기에서도 이어서 활용할 수 있습니다.

## 프로젝트 방향

단어를 읽는 것에서 끝나지 않고, **스스로 떠올리고 반복해서 확인하는 학습 경험**을 만드는 데 초점을 맞췄습니다.

- **간단한 학습 동선**: Day 선택부터 단어 확인, 저장, 복습까지 연결합니다.
- **필요한 정보만 확인**: 단어·발음·뜻을 숨겨 회상 연습을 하고, 막히는 부분만 잠깐 펼쳐볼 수 있습니다.
- **눈에 보이는 학습 기록**: 끝까지 학습한 Day를 표시해 다음 학습을 선택하기 쉽게 합니다.
- **계정 없이도 시작**: 브라우저 저장을 지원하고, 필요할 때 계정 단어장으로 옮길 수 있습니다.

## 주요 기능

### 하루 50개씩, 카드로 배우는 일본어

Day 01부터 Day 20까지 각 50개의 단어를 제공합니다. 카드에는 일본어 단어, 발음, 한국어 뜻, 예문과 해석을 함께 표시합니다.

카드를 왼쪽으로 밀면 아는 단어로 넘기고, 오른쪽으로 밀면 복습할 단어로 저장합니다. 같은 동작을 버튼으로도 제공해 터치와 마우스 환경에서 모두 학습할 수 있습니다.

### 숨김 설정과 잠깐 보기

일본어 단어·발음·뜻을 선택적으로 숨길 수 있으며, 일본어와 뜻의 숨김 설정은 예문에도 적용됩니다. 숨긴 항목을 터치하면 **해당 부분만 3초 동안 표시**되고, 다시 터치하면 즉시 숨겨집니다.

단어와 예문, 예문 해석의 임시 표시는 서로 독립적으로 동작합니다. 다음 단어로 이동하면 임시 표시는 초기화되고, 사용자가 선택한 숨김 설정은 유지됩니다.

### 나만의 단어장

학습 중 저장한 단어를 모아 다시 확인하고, 이전·다음 단어로 이동하거나 저장을 해제할 수 있습니다.

비로그인 상태에서는 현재 브라우저에 저장하고, 로그인 상태에서는 계정별 단어장을 사용합니다. 브라우저에 저장한 단어를 계정으로 가져올 때는 중복 없이 추가하며 기존 브라우저 기록도 유지합니다.

### Day별 학습 완료 표시

**마지막 단어를 넘겨 학습을 종료한 시점**에 해당 Day의 완료 기록을 저장합니다. 마지막 단어를 화면에 띄우기만 하거나 중간에 학습을 나가면 완료로 처리하지 않습니다.

완료한 Day는 목록에서 초록색 배경과 우상단 체크 표시로 구분됩니다. 다시 학습하더라도 기존 완료 기록과 최초 완료 시각은 유지됩니다.

### 발음 듣기와 화면 환경

브라우저의 음성 합성 기능으로 단어와 예문을 일본어로 들을 수 있습니다. 음성 지원 여부에 따른 안내를 제공하며, 정보 숨김 중에도 듣기 기능을 사용할 수 있습니다.

모바일과 데스크톱을 고려한 반응형 화면, 라이트·다크 테마, 키보드로 조작할 수 있는 버튼과 상태 안내를 제공합니다.

## 설계와 구현에서 고려한 점

### 학습 콘텐츠와 사용자 기록 분리

단어와 예문은 Day별 JSON으로 관리하고, 개인 단어장과 학습 완료 기록은 사용자 데이터로 분리했습니다. 학습 페이지는 `generateStaticParams`로 Day별 경로를 미리 생성하고, 인증 상태에 따라 달라지는 기록과 카드 조작은 클라이언트에서 처리합니다.

고정된 학습 콘텐츠와 변경되는 사용자 상태의 역할을 나누어, 같은 단어 데이터로 일반 학습과 개인 단어장 복습을 구성했습니다.

### 저장 성공을 기준으로 하는 화면 전환

저장 요청을 보냈다는 이유만으로 다음 상태를 보여주지 않도록 구현했습니다. 단어 저장이 실패하면 현재 카드에 머물고, 마지막 단어에서는 완료 기록까지 저장된 뒤 종료 화면으로 이동합니다.

처리 중 중복 동작을 방지하고, 실패 시 재시도할 수 있는 안내를 제공합니다. 계정 전환이나 화면 이동 전에 시작된 비동기 요청의 결과가 새 화면 상태에 반영되지 않도록 관리합니다.

### 사용자별 데이터 격리와 중복 방지

단어장은 `(user_id, word_id)`, 학습 완료 기록은 `(user_id, day_id)`를 복합 기본 키로 사용합니다. 반복 저장과 재학습이 중복 기록을 만들지 않도록 처리했습니다.

DB의 RLS 정책에서 사용자 소유권을 확인해 다른 계정의 기록에 접근하지 못하도록 제한합니다. 비로그인 기록은 브라우저에 별도로 보관하며, 로그인·로그아웃 시 계정 기록과 섞이지 않도록 저장 대상을 구분합니다.

### 학습 설정과 일시적인 표시 상태 분리

카드 숨김 설정은 지속되는 사용자 선호로 저장하고, 잠깐 보기는 각 항목의 일시적인 상태로 관리합니다. 한 항목을 확인해도 다른 항목이나 전체 숨김 설정이 바뀌지 않습니다.

타이머는 항목이 사라지거나 표시 상태가 바뀔 때 정리하고, 터치 이벤트가 카드 드래그로 전달되지 않도록 처리해 잠깐 보기와 카드 넘기기가 충돌하지 않게 했습니다.

# 일본어 단어 JSON

`일본어 단어.pdf`의 DAY01~DAY20에 있는 전체 1,000개 항목을 날짜별로 정리했습니다. 각 일자의 3쪽에 있는 단어 50개를 원본 번호순으로 담았습니다. 원본에 같은 표기가 중복된 항목도 그대로 포함했습니다.

각 파일은 UTF-8(BOM 없음)로 저장한 JSON 객체입니다. 최상위 `day`는 날짜 식별자이고 `words`는 단어 객체 50개의 배열입니다.

```json
{
  "day": "day01",
  "words": [
    {
      "word": "あいさつ",
      "mean": "인사",
      "furigana": "あいさつ",
      "exampleSentence": "朝、先生にあいさつをします。",
      "exampleSentenceMean": "아침에 선생님께 인사합니다."
    }
  ]
}
```

위 예시는 구조 설명을 위해 한 단어만 표시했습니다. 실제 파일에는 각각 50개가 있습니다.

| 필드 | 내용 |
| --- | --- |
| `word` | PDF에 나온 일본어 표기 |
| `mean` | 한국어 뜻. 여러 뜻은 세미콜론으로 구분 |
| `furigana` | 단어 전체의 히라가나 읽기. 장음 `ー`와 문형 기호 `～`는 유지 |
| `exampleSentence` | 해당 뜻을 보여 주는 일본어 예문 |
| `exampleSentenceMean` | 예문의 한국어 해석 |

PDF는 읽는 법과 뜻을 채우는 시험지이므로 해당 칸이 비어 있습니다. 읽기와 한국어 뜻을 보충했고, 예문과 해석은 새로 작성했습니다. 원교재의 정답이나 예문을 옮긴 자료는 아닙니다. 동사와 형용사는 예문에서 자연스럽게 활용했습니다.

히라가나만 제시되어 원래 의도한 한자나 뜻을 확정할 수 없는 항목은 기본 학습 의미를 선택했습니다. 주요 해석은 다음과 같습니다.

| 원본 항목 | 데이터에 사용한 해석 |
| --- | --- |
| DAY05 `かぐ` | 가구(家具) |
| DAY06 `きかい` | 기계(機械), 기회(機会). 예문은 기계 |
| DAY09 `さす` | 우산을 쓰다, 가리키다. 예문은 우산을 쓰다 |
| DAY09 `しめる` | 매다·조이다. 별도 `閉める` 항목은 닫다 |
| DAY10 `しゅうかん` | 기간을 나타내는 주간(週間). 같은 날 `習慣`은 습관 |
| DAY11 `そば` 두 항목 | 각각 메밀국수와 곁·옆으로 구분 |
| DAY12 `ソフト` | 소프트웨어 |
| DAY12 `たずねる` | 방문하다(訪ねる), 묻다(尋ねる). 예문은 방문하다 |
| DAY13 `つく`, `つける` | 각각 불이 켜지다, 불을 켜다를 예문에 사용 |
| DAY15 `はく` 두 항목 | 각각 신다·하의를 입다(履く·穿く), 쓸다(掃く)로 구분 |
| DAY16 `はし` | 다리(橋). 젓가락은 DAY04 `おはし`에 수록 |
| DAY16 `ひく` | 악기를 연주하다(弾く). 별도 `引く` 항목은 당기다 |
| DAY17 `ふく` | 불다(吹く), 닦다(拭く). 예문은 바람이 불다 |

위 항목의 의미 배정은 원교재 정답과 다를 수 있습니다. `係り`, `火よう日`, `本だな`, `向い` 등의 표기는 PDF를 유지했습니다. 읽기가 여럿인 단어는 예문에 맞는 대표 읽기 하나를 사용했습니다(예: `明日` → `あした`, `毎年` → `まいとし`).

검증: JSON 20개, 각 50개 항목, 총 1,000개 항목의 개수와 다섯 필드의 문자열 값, 빈값 및 문자 손상 여부, ZIP 내부 JSON의 일치 여부를 검사했습니다.
